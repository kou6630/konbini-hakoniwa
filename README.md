# コンビニはじめちゃいました

3D の箱庭コンビニを経営するシミュレーションゲームです（Windows）。

おにぎりを炊いて・握って・棚に並べて、お客さんをさばきましょう。
レベルが上がると、梅・おかかのおにぎり、水の冷蔵庫、店の増築などが解禁されます。

## ダウンロード

**[インストーラを直接ダウンロード（最新版）](https://github.com/kou6630/konbini-hakoniwa/releases/latest/download/KonbiniHakoniwa-Setup.exe)**
して実行してください。（[Releases ページ](https://github.com/kou6630/konbini-hakoniwa/releases/latest) からも入手できます）

- インストールすると、スタートメニューとデスクトップに「コンビニはじめちゃいました」ができます。
- 起動するたびに新しいバージョンを自動で確認し、見つかればダウンロードして更新します（セーブデータは消えません）。
- 署名のない個人製作のアプリのため、初回のインストール時に Windows の警告
  （「WindowsによってPCが保護されました」）が出ることがあります。
  「詳細情報」→「実行」で進めてください。

## 遊び方

おにぎりを炊いて・握って・棚に並べて、お客さんをさばきましょう。お客さんは「買いたいもの」を持って来店します。
希望どおり買ってもらえれば店の評価が上がり、客足が増えます。品切れで別のものを買わせたり、帰らせたりすると評価が下がります。

| レベル | 解禁されるもの |
|---|---|
| Lv.1 | 塩むすび |
| Lv.2 | 梅むすび・おかかむすび |
| Lv.3 | 店の増築、飲み物の冷蔵庫（水） |
| Lv.4 | サンドイッチ台、サンドのケース（たまごサンド） |
| Lv.5 | 揚げ物台、ホットスナックケース（から揚げ）、お茶 |
| Lv.6 | ハムサンド |
| Lv.7 | コロッケ、コーヒー |
| Lv.8 | 鮭むすび、お菓子棚（ポテトチップス） |
| Lv.9 | ツナマヨむすび、弁当台・お弁当のケース（唐揚げ弁当） |
| Lv.10 | のり弁当、チョコレート |
| Lv.11 | スイーツケース（プリン） |
| Lv.12 | シュークリーム |
| Lv.13 | 蒸し器台・中華まんケース（肉まん） |
| Lv.14 | タバコ棚（たばこ・赤） |
| Lv.15 | あんまん |
| Lv.16 | たばこ・緑 |

食材や仕入れ品（飲み物・お菓子・スイーツ）は、バックヤードの搬入口（手前の壁の左）から注文します。
ショップ（`B`）では、お店のアップグレードのほか、**ロボット**（レジロボ・炊飯ロボ・握りロボ・品出しロボ・厨房ロボ・警備ロボ）を買えます。買い切りで給料はありませんが、**充電スポットを買わないと動きません**。ロボットは Lv.5 まで強化でき（速さと電池の持ちが上がる）、電池が減ると空いている充電スポットへ自分で充電に行きます。
雇うと、1日の終わりに給料がかかります。

## 1日の流れとレイアウト編集

- 1日は 7:00〜22:00（実時間で約4分）。**開店中だけ時間が進み**、22:00 になると自動で閉店して次の日の朝になります。「開店する」で次の日を始めます。
- 閉店中（お客さんが全員帰ったあと）は、床のタイル（1マス＝0.5m）の上で**設備を動かせます**（レイアウト編集）。炊飯器・握り台・トレー台・レジ・棚・調理台・売り場のケースなど、すべて対象です。
  - 設備をクリックして選び、置きたい場所でクリック。`R` で90°回転、`Esc` でキャンセル、`L` で完了。
  - 編集中は**時間が止まります**。入口や搬入口をふさぐ、通れない場所ができる、他の設備とかぶる、といった置き方はできません。
  - まだ解禁されていない設備の「予約枠」も動かせます。「初期配置に戻す」で最初の配置に戻ります。
- 店の前には**駐車場と道路**があります。Lv.2 から、車で来るお客さん（1〜4人）が駐車場に停めて降りてきます。
  - Lv.7 から、昼と夕方に**観光バス**が止まり、一度にたくさんのお客さんが降りてきます。
  - Lv.8 から、夜（19時すぎ）に**ヤンキー**が車で来て入口の前に座り込むことがあります。いる間は客足が落ち、入れずに帰る人が出ます。閉店すると帰っていきます。**警備ロボ**（Lv.8 から購入可）がいれば、入口の前まで行って追い払い、いる間の客足の落ち込みもやわらぎます。
- **店の広さ**はショップで買えます（Lv.3 / 6 / 10 / 14 から、3,000 / 8,000 / 18,000 / 40,000円）。1回ごとに店が右へ 2.5m 広がり、最大4回。広げるまで冷蔵庫や売り場のケースは置けません。
- 設備の名前や在庫の表示は、**カーソルを近づけたときだけ**出ます。

## 操作

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` / 矢印キー / 画面クリック |
| 操作する（炊く・置く・会計など） | `E` / `Space` |
| ショップ | `B` |
| 開店 / 閉店 | `O`（画面左上のボタンでも） |
| レイアウト編集（閉店中だけ） | `L`（画面左上のボタンでも） |
| ポーズ | `Esc` |
| 視点の回転 / ズーム / リセット | 右ドラッグ / ホイール / `R` |
| 全画面 | `F11` |

## 開発者向け

```bash
npm install
npm start            # ビルドして起動
npm run dist         # インストーラを作る（dist-installer/）
```

### 新しいバージョンを公開する

```bash
npm version minor --no-git-tag-version   # 1.1.0 -> 1.2.0（patch / major でも可）
git add -A && git commit -m "v1.2.0: ..." && git tag v1.2.0
git push origin main && git push origin v1.2.0
npm run release                          # ビルドして GitHub Releases にアップロード（gh にログイン済みなら自動）
```

アプリは起動のたびに GitHub Releases の最新版を確認し、新しければ自動で更新します。

### 技術

Electron + Three.js（モデルはすべてコードで生成）。ゲーム本体は `src/`、Electron 側は `main.js` / `preload.js`。
