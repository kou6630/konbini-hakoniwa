# コンビニはじめちゃいました

3D の箱庭コンビニを経営するシミュレーションゲームです（Windows）。

おにぎりを炊いて・握って・棚に並べて、お客さんをさばきましょう。
レベルが上がると、梅・おかかのおにぎり、水の冷蔵庫、店の増築などが解禁されます。

## ダウンロード

**[インストーラを直接ダウンロード（最新版）](https://github.com/kou6630/konbini-hakoniwa/releases/latest/download/KonbiniHakoniwa-Setup.exe)**
して実行してください。（[Releases ページ](https://github.com/kou6630/konbini-hakoniwa/releases/latest) からも入手できます）

- インストールすると、スタートメニューとデスクトップに「コンビニはじめちゃいました」ができます。
- 起動するたびに新しいバージョンを自動で確認し、見つかればダウンロードして更新します（セーブデータは消えません）。
- 署名のない個人製作のアプリのため、初回のインストール時に Windows の警告
  （「WindowsによってPCが保護されました」）が出ることがあります。
  「詳細情報」→「実行」で進めてください。

## 遊び方

おにぎりを炊いて・握って・棚に並べて、お客さんをさばきましょう。お客さんは「買いたいもの」を持って来店します。
希望どおり買ってもらえれば店の評価が上がり、客足が増えます。品切れで別のものを買わせたり、帰らせたりすると評価が下がります。

| レベル | 解禁されるもの |
|---|---|
| Lv.1 | 塩むすび |
| Lv.2 | 梅むすび・おかかむすび |
| Lv.3 | 店の増築、飲み物の冷蔵庫（水） |
| Lv.4 | サンドイッチ台、サンドのケース（たまごサンド） |
| Lv.5 | 揚げ物台、ホットスナックケース（から揚げ）、お茶 |
| Lv.6 | ハムサンド |
| Lv.7 | コロッケ、コーヒー |

食材は、バックヤードの搬入口（手前の壁の左）から注文します。
ショップ（`B`）では、お店のアップグレードのほか、**アルバイト**（レジ係・炊飯係・握り係・品出し係・厨房係）を雇えます。
雇うと、1日の終わりに給料がかかります。

## 操作

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` / 矢印キー / 画面クリック |
| 操作する（炊く・置く・会計など） | `E` / `Space` |
| ショップ | `B` |
| ポーズ | `Esc` |
| 視点の回転 / ズーム / リセット | 右ドラッグ / ホイール / `R` |
| 全画面 | `F11` |

## 開発者向け

```bash
npm install
npm start            # ビルドして起動
npm run dist         # インストーラを作る（dist-installer/）
```

### 新しいバージョンを公開する

```bash
npm version minor --no-git-tag-version   # 1.1.0 -> 1.2.0（patch / major でも可）
git add -A && git commit -m "v1.2.0: ..." && git tag v1.2.0
git push origin main && git push origin v1.2.0
npm run release                          # ビルドして GitHub Releases にアップロード（gh にログイン済みなら自動）
```

アプリは起動のたびに GitHub Releases の最新版を確認し、新しければ自動で更新します。

### 技術

Electron + Three.js（モデルはすべてコードで生成）。ゲーム本体は `src/`、Electron 側は `main.js` / `preload.js`。
